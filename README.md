# ZipAI (index.html 중심 설명서)

## 1. 프로젝트명

- **프로젝트명:** ZipAI (집아이) - AI 기반 청년 주거 안전 플랫폼
- **Demo URL:** https://zipai2026.netlify.app/
- **시연 방법:**
  1. 배포된 데모 URL(https://zipai2026.netlify.app/)에 접속합니다.
  2. 메인 화면(index.html)에서 지도 기반 매물(일반 전·월세 및 LH·공공임대)을 탐색하고 필터링해 봅니다.
  3. 사기방지 메뉴에서 계약 안전성 체크리스트를 수행하고, 전세가율 계산기를 이용해 위험도를 진단한 뒤 최종 종합 진단 리포트를 확인합니다.
  4. 행복주택 메뉴에서 자격 요건(나이, 소득, 자산 등)을 입력하여 신청자격 간편진단을 수행합니다.
  5. 고객센터에서 FAQ 검색 및 1:1 문의를 등록하고, 관리자 페이지(`templates/admin/admin.html`)에서 접수된 문의 답변 등록 및 상태 관리를 시연합니다.
     *(주의: Render 무료 플랜을 사용하므로, 최초 접속 시 백엔드 서버의 Cold Start로 인해 로그인, 찜, 문의 등록 등 서버 API 기능 동작에 약 1분의 지연이 발생할 수 있습니다. 이 경우 잠시 기다린 후 새로고침하여 시연해 주시기 바랍니다.)*
- **로그인 방법:**
  - **일반 사용자:** 로그인 페이지(`templates/member/login.html`)에서 회원가입(`signup.html`)을 진행한 후, 생성한 계정으로 로그인하여 마이페이지, 찜하기, 매물 등록 및 1:1 문의 기능을 시연해 볼 수 있습니다.
  - **관리자:** 관리자 기능(`admin.html`)을 테스트하려면 `admin` 계정으로 로그인해야 합니다. 회원가입 시 아이디를 `admin`으로 가입하거나, 서버 데이터베이스에 등록된 관리자 계정으로 로그인하여 사용할 수 있습니다.

## 2. 프로젝트 소개

**ZipAI(집아이)**는 청년 및 사회초년생이 안전하게 전·월세 매물을 탐색하고 주거 안전성을 분석할 수 있도록 지원하는 **AI 기반 청년 주거 안전 플랫폼**의 프론트엔드 어플리케이션입니다.

메인 화면인 [index.html](file:///c:/won/git/zipai/index.html)을 중심으로 지도 기반 매물 탐색을 제공하며, 치안 데이터 및 전세사기 진단 도구를 연계하여 주거 결정의 위험 요소를 직관적으로 파악할 수 있도록 설계되었습니다.

---

## 3. 프로젝트 목표

- **안전 정보 지도 통합**: 매물 탐색 지도에 치안 시설(CCTV, 비상벨, 경찰서) 및 위험 주의 구간 정보 등을 시각적으로 결합하여 제공합니다.
- **자가 진단 기반 사기 예방**: 전세사기 유형별 체크리스트와 간편한 전세가율 계산 도구를 제공해 계약 위험을 예방합니다.
- **주거 정책 정보 제공**: 복잡한 등기부 해독 요령과 정부 대출, 월세 지원 등의 금융 혜택 정보를 한곳에 모아 정보 비대칭을 해결합니다.
- **일관되고 편리한 사용자 경험(UX)**: 로그인, 상세 매물 탐색, 계약 자가진단, 고객센터로 이어지는 자연스러운 동선을 구축합니다.
- **반응형 최적화**: PC, 태블릿, 모바일 등 다양한 기기에 유연하게 대응하는 반응형 레이아웃을 제공합니다.

---

## 4. 기획 의도

청년층 및 사회초년생이 주거지를 선택할 때 비용 외에도 치안과 안전 여부가 매우 중요한 결정 요인입니다. 그러나 기존 부동산 플랫폼은 매물의 가격과 구조 중심의 거래 정보만 강조하여, 안전 정보나 전세사기 가능성을 판단하기 위해서는 공공 및 지자체 사이트를 따로 찾아야 하는 번거로움이 있었습니다.

집아이는 **"데이터로 찾고, 안전하게 계약하는 플랫폼"**이라는 철학 하에, 지도상에서 실시간으로 안전 인프라를 분석하고, 계약 전 5분 자가진단을 거쳐, 대상별 정부 맞춤형 금융지원정책을 연동하는 올인원 주거 안심 서비스를 지향합니다.

## 5. 기술 스택

- **기본 웹 기술**: HTML5, CSS3, JavaScript (ES6+ Vanilla JS)
- **지도 연동 API**: 네이버 지도 API (Naver Map API v3 SDK)
- **아이콘 및 폰트**: Font Awesome Icons, Google Fonts (Noto Sans KR, IBM Plex Sans KR)
- **디자인 표준화**: CSS Custom Properties를 이용한 디자인 토큰화 (색상, 간격, 타이포그래피 표준화)
- **로컬 임시 저장소**: Web Storage API (`localStorage`)를 활용한 찜 목록 및 문의 데이터 상태 관리

## 7. UI 핵심 기능

- **매물 검색 및 지도 필터링 (`index.html`)**
  - 네이버 지도 API 기반 매물 위치 시각화 및 클릭 시 슬라이드인 상세 패널 구현
  - 보증금 및 월세 범위를 조절하는 슬라이더 필터링 제공
  - 일반 전·월세와 LH·공공임대 매물 탭 전환 및 경기도 31개 시·군 기준 필터링 제공
  - 관심 있는 매물의 하트 아이콘 클릭을 통한 실시간 찜 기능 (`localStorage` 연동)
- **사기방지 및 계약 진단**
  - 3단계 계약시기별 체크리스트 기반 점수 산정 및 진단 결과 리포트 연계
  - 매매가 대비 보증금 비율을 통해 위험 등급을 계산하는 전세가율 계산기
  - 아코디언 방식으로 쉽게 찾아보는 등기부등본 읽는 법 및 계약 주의사항
- **종합 위험안전도**
  - 치안 데이터(CCTV, 비상벨, 경찰서)의 오버레이 마커 표출
  - 안전 지표(6대 영역)를 가시적인 그래프로 보여주는 분석 대시보드
- **청년 금융 정책 및 행복주택 정보**
  - 버팀목 대출, 보증보험 등 금융 상품 추천 및 대출 이자/상환액 시뮬레이터 제공
  - 신청 자격(나이, 소득, 자산)을 입력하여 행복주택 신청 가능 여부를 알아보는 간편 진단기
- **고객센터 및 마이페이지**
  - 가상 FAQ 검색 기능 및 1:1 문의글 작성/이력 목록 확인
  - 회원 정보 수정 및 찜한 매물 관리가 이루어지는 마이페이지 제공

## 8. 개발 일정

### 기본 개발 시간

- **하루 2시간씩 총 6주(42일) 진행** (주당 12시간, 총 72시간)

### 주간 개발 일정

- **1주차**: 프로젝트 요구사항 정의, 서비스 기획 및 와이어프레임 설계, CSS 디자인 토큰(스타일 가이드) 정의
- **2주차**: 공통 반응형 헤더/푸터 마크업 및 스타일 구축, 회원가입 및 로그인 페이지 개발과 localStorage 가상 인증 설계
- **3주차**: 메인 페이지 개발 - 네이버 지도 API 통합, 매물 마커 매핑 및 줌 레벨 연동, 다중 조건 검색 필터(슬라이더 포함) 구현
- **4주차**: 사기방지 진단 도구 구축 - 3단계 계약 체크리스트, 전세가율 계산기, 종합 점수 리포트 페이지 구현
- **5주차**: 금융지원 및 행복주택 정보관 개발, 고객센터 페이지 구성(자주 묻는 질문 검색 및 1:1 문의 접수)
- **6주차**: 사용자 시나리오 기반 전체 동선 테스트, 모바일 반응형 레이아웃 미세조정, 버그 수정 및 최종 배포

## 11. 개선 보완 사항

- **코드 및 스타일 최적화**: 공통 레이아웃 관련 스타일의 중복 정의를 제거하고 `common.css` 디자인 토큰으로 단일화하여 유지 보수성을 높입니다.
- **예외 입력 차단**: 계산기 등에 0, 음수 또는 숫자가 아닌 텍스트 입력 시 `NaN` 등의 오류가 발생하지 않도록 프론트엔드 검증을 보강합니다.
- **데이터 영속성 극복**: 현재의 브라우저 로컬 저장소(`localStorage`) 기반 상태 관리를 공통 백엔드 데이터베이스 기반으로 승격시켜 데이터 손실을 방지합니다.

## 12. 향후 개발 예정

- **Spring 백엔드 구축**
  - Spring Boot 3.x와 JPA를 기반으로 견고한 REST API를 설계하고 Aiven MySQL 클라우드 DB를 구축하여 회원 정보, 매물 정보 및 문의 데이터를 통합 데이터베이스에서 처리합니다.
- **RPA 데이터 수집**
  - 국토교통부 실거래가 데이터와 LH 청약플러스의 공공주택 모집공고 데이터를 실시간/주기적으로 크롤링 및 수집하는 자동화 배치 프로그램(RPA)을 개발하여 최신 부동산 데이터를 매일 갱신합니다.
- **AI 알고리즘 도입**
  - 사용자의 라이프스타일, 예산 선호도, 검색 이력 데이터를 기반으로 AI 추천 알고리즘을 구축하여 맞춤형 매물을 챗봇 형태로 추천합니다.
  - 등기부등본 이미지/PDF 업로드 시 OCR 모델을 사용해 갑구/을구의 권리 변동 및 근저당 설정을 자동 추출하여 전세가율에 자동 반영하는 안심 분석 기술을 도입합니다.

## 13. 기대 효과

- **청년 세입자 사기 피해 감소**: 복잡한 법적 용어 분석 없이도 사용자가 스스로 전세가율과 안전 리포트를 얻어 사기성 매물을 사전 식별할 수 있습니다.
- **정량적 데이터 기반 안심 거주지 탐색**: 정성적인 느낌을 넘어 CCTV 밀도, 치안 등급 등 실제 수치 데이터 기반의 객관적인 위험도를 검토해 안전한 거주 환경을 확보합니다.
- **청년 복지 정책 수혜율 극대화**: 파편화되어 있는 청년 버팀목 대출, 월세 지원, 행복주택 신청 정보 등을 한곳에 연결하여 정책 접근성을 크게 향상시킵니다.
- **향후 확장 잠재력**: 명확한 프론트엔드-백엔드 데이터 통신 구조 설계를 바탕으로 향후 AI 분석 알고리즘과 OCR 검인 모듈의 이식이 용이합니다.
