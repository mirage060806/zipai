# 경기도 매물 데이터 연결

## 실행

이 프로젝트는 별도 패키지 설치 없이 Node.js 18 이상에서 실행됩니다.

PowerShell:

```powershell
node server.js
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## LH·공공임대 실제 공고 연결

1. 공공데이터포털에서 `한국토지주택공사_분양임대공고문 조회 서비스` 활용을 신청합니다.
2. 발급된 `일반 인증키(Decoding)`를 서버 환경변수에 지정합니다.
3. 같은 터미널에서 서버를 실행합니다.

```powershell
$env:PUBLIC_DATA_SERVICE_KEY="발급받은 일반 인증키"
node server.js
```

서비스키는 브라우저 코드나 Git 저장소에 넣지 않습니다. 서버는 경기도 코드 `41`, 임대주택·주거복지, `공고중` 조건으로 조회하고 결과를 10분 동안 캐시합니다.

## 일반 전·월세

상단의 `매물 등록`을 누르면 경기도 31개 시·군의 일반 매물을 로컬 브라우저에 등록할 수 있습니다. 로컬 버전의 데이터는 `localStorage`에만 저장되며 다른 사용자와 공유되지 않습니다.

실제 운영 전환 시에는 다음 항목이 필요합니다.

- 서버 데이터베이스와 중개사 로그인
- 도로명주소 좌표 변환
- 중개사무소 및 매물 소유 관계 검증
- 매물 최종 확인일과 자동 만료
- 거래완료 처리와 허위매물 신고

초기 화면의 `등록 예시` 항목은 기능 확인용이며 실제 계약 가능한 매물이 아닙니다.
