# 관리자 매물 파일

`성남시_시연용_일반매물_10건.xlsx`는 관리자 업로드 형식 확인을 위한 가상 데이터입니다.

- 모든 행의 `데이터구분`은 `시연용`입니다.
- 모든 행의 `실제매물여부`는 `아니오`입니다.
- 주소와 연락처는 실제 계약에 사용할 수 없는 예시 값입니다.
- 지도 표시 확인을 위한 성남시 각 동의 대표 좌표가 포함되어 있습니다.

`node server.js`로 사이트를 실행하면 서버의 `/api/general-properties`가 이 Excel 파일을 읽어 일반 전·월세 목록과 지도에 자동 반영합니다. Go Live 또는 `index.html` 직접 열기에서는 서버 API를 사용할 수 없어 기존 시연 데이터만 표시됩니다.
